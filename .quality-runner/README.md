# Quality Runner evidence boundary

The repository owns the behavior contract in `.pronto/behavior-assurance.json`.
Quality Runner receipts must be produced by the approved producer against a
committed contract and stored under `.quality-runner/behavior-assurance/receipts`.

No receipt is hand-authored here. Until a committed revision is assessed and a
Quality Runner audit/replay/feed is available, repository assurance remains
partial and the GitHub provider behavior remains unverified.
